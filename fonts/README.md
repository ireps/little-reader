# Andika font

Andika (by SIL) is made for early readers: a single-story *a* and *g*, and clearly different *b d p q*.

Add these files to this folder:

- `Andika-Regular.woff2` and `Andika-Bold.woff2` (or the `.ttf` versions; the CSS accepts either)
- `OFL.txt`, the licence, from the same download

Download from SIL: https://software.sil.org/andika/download/

Until they're here, the app falls back to Trebuchet MS or Verdana, and the browser log shows 404s for the missing files.
